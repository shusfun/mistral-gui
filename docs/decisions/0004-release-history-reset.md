# 0004 从 0.1.1 开始应用发布历史

## 决定

- 清理初始化前的应用 Release 和对应标签，以 `0.1.1` 作为第一条应用发布。由 GitHub 自动确定最新发布。
- 以当前正式 Release 为递增基准，默认只增加一个补丁号，下一版为 `0.1.2`。跳过补丁号、提高次版本或主版本，须取得仓库所有者对目标版本的明确授权。
- 独立运行时和 OCR 资源沿用各自的发布通道。

## 影响

已装更高版本的用户可用 `0.1.1` 安装包覆盖安装。旧应用发布链接随清理失效。

## 依据

仓库所有者于 2026-11-19 确认清理旧应用发布，两仓以 `0.1.1` 重新起步，保留运行时和 OCR 资源。
