# 0002 图片翻译默认原位显示

## 背景

用户需要同时看见译文在原图中的位置、复制完整译文，以及编辑识别原文。图片比例或翻译结果变化时，工具栏和文本区应保留在原位。

## 决定

- 图片翻译默认在识别到的原文位置使用不透明底色覆盖并显示译文，支持切回原图。框选区域中的识别坐标换算回整图。
- 页面依次显示工具栏、图片预览、可复制的完整译文和可编辑的识别原文。预览为同一窗口尺寸保留稳定高度。长文本在各自区域内滚动，窗口放不下各区最小高度时由页面滚动。
- 编辑原文并重译后切回原图，更新下方完整译文。
- 沿用 0001 的段落重建、按原换行翻译选项和文本仅在当前页面内保存的决定。

## 考虑过的方案

- 选区旁的浮层逐段对照。用户改为要求在原图内查看译文位置，并在图下阅读、选择和复制完整文本。
